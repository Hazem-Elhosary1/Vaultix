# Project Roadmap – Vaultix

### ✅ Implemented
- [x] Master Password & PIN Security
- [x] Biometric Authentication (Strong)
- [x] AES-256-GCM Encryption (Database & Files)
- [x] Autofill Service with Interactive UI
- [x] File vault (Streaming Encryption)
- [x] Identity documents management
- [x] Expiry alerts for cards/IDs (Background Worker)
- [x] Emergency Recovery Key (Zero-Knowledge)
- [x] Security Audit Dashboard
- [x] Premium Dashboard with Stats & Distribution (Unified Overview Card)
- [x] Global Search & Categories

### 🔜 Sprint backlog: Selected Enhancements
- [ ] **📋 Password History UI per Item**: Display historical decrypted passwords with strength & age in the Item Detail screen.
- [ ] **📊 Password Age Indicator**: Color-coded age badges (green, yellow, red) in Category lists based on last update timestamp.
- [ ] **🏷️ Tags / Labels System**: Add/remove labels on vault items, supporting fast filtering by tags in Category and Search screens.
- [ ] **📤 Share / Export Individual Item**: Secure standard text sharing or QR code generation for off-screen credential sharing.
- [ ] **🔄 TOTP / 2FA Authenticator**: Support TOTP generation. Allow scanning/typing 2FA keys and showing the 30s ticking code alongside passwords.
- [ ] **🗂️ Custom Categories / Folders**: Extend the File Vault folder concept to passwords, notes, IDs, and cards for custom organization.
- [ ] **🔔 Customizable Notifications**: Notification settings panel allowing toggles/thresholds for card expiry, weak passwords, and database auto-backups.
- [ ] **📱 Home Screen Widgets**: Compact widget for quick-access passwords/notes or generating new secure passcodes right from the launcher.
