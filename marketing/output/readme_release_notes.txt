Play Store upload tips:
- App icon: provide 512x512 PNG (transparent allowed), with rounded safe area.
- Feature graphic (optional): 1024x500 JPEG (may use `cover-full-wide.png` cropped if needed).
- Screenshots: upload vertical phone screenshots (use @2x exports). Provide 4–8 screenshots showing core flows.
- Promo video: upload 16:9 MP4 (hosted on YouTube or through Play Console). Provide trailer link or upload file.

File naming conventions:
- Use lowercase, dashes, and @2x suffix for high-res phone assets.
- Include a `readme_release_notes.txt` explaining which files are final and any alt-versions.

Checklist before upload:
- All screenshots and cover images are RGB, sRGB color profile, no alpha for JPEGs.
- Filenames match the ones listed above.
- Provide copy (short description, full description, keywords) in both Arabic and English.
- Include app store video link and thumbnail.
